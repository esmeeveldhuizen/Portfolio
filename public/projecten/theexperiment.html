The Experiment: Nature Edition

A full VR survival experience built in Unity within four weeks.

Play on Itch.io

Project Overview

The Experiment: Nature Edition is a first-person VR survival game created by a team of 2 developers and 5 artists in just four weeks. Set in a forgotten laboratory overtaken by nature, players must fight off hostile robots while searching for a way out.

Armed with a weapon and a shield, you must survive waves of mechanical enemies, collect power-ups, and unlock doors using gears dropped by the final robot in each wave. Every decision counts as you fight for survival in this dangerous, decaying environment.

Gameplay Mechanics

The Experiment: Nature Edition offers an intense and immersive VR experience. Players explore a mysterious laboratory where malfunctioning robots patrol every corridor. Use your blaster to eliminate threats and your energy shield to block incoming attacks. Each defeated robot may drop power-ups, but beware: some also trigger new waves of enemies.

The ultimate goal is to survive long enough to collect the gears that open each door, progressing deeper into the lab until you finally find the escape.

Development Process

The game was built using Unity (C#) for Meta Quest 3 and was designed specifically for VR interaction. I was responsible for gameplay programming, environmental setup, and the interaction systems such as door unlocking, fading transitions, and collectible mechanics.

Our focus was on creating a smooth and immersive VR experience, balancing performance, physics, and player comfort while implementing engaging combat and environmental storytelling.

Code Samples


public class OpenDoor : MonoBehaviour
{
    [SerializeField] Transform door;
    [SerializeField] public GameObject handle;
    private float openSpeed = 0.5f;
    private bool handleInPlace = false;

    private Vector3 startPos;
    private Vector3 targetPos;

    public AudioSource Audio;
    public AudioClip openDoor;
    public AudioClip WrongDoor;

    void Start()
    {
        startPos = door.position;
        targetPos = new Vector3(startPos.x, startPos.y + 3f, startPos.z);
    }

    void Update()
    {
        if (handleInPlace)
            door.position = Vector3.Lerp(door.position, targetPos, Time.deltaTime * openSpeed);
    }

    private void OnTriggerEnter(Collider other)
    {
        if (other.gameObject == handle)
        {
            StartCoroutine(WaitBeforeOpening());
            handle.transform.SetParent(door);

            if (this.gameObject.name == "FirstDoor")
                WaveSpawner.Instance.Door1Opened = true;
            if (this.gameObject.name == "SecondDoor")
                WaveSpawner.Instance.Door2Opened = true;
            if (this.gameObject.name == "LastDoor")
                WaveSpawner.Instance.FinalDoorOpened = true;
        }
        else if (other.CompareTag("Gear"))
        {
            Audio.clip = WrongDoor;
            Audio.Play();
        }
    }

    private IEnumerator WaitBeforeOpening()
    {
        yield return new WaitForSeconds(3f);
        handleInPlace = true;
        Audio.clip = openDoor;
        Audio.Play();
    }
}


public class FadeIn : MonoBehaviour
{
    [SerializeField] private GameObject sphere;
    float fadeAmount = 0;

    public void FadeBegin()
    {
        sphere.SetActive(true);
        StartCoroutine(BlackScreenFadeIn());
    }

    public IEnumerator BlackScreenFadeIn()
    {
        while (fadeAmount < 1)
        {
            sphere.GetComponent().material.color = new Color(0, 0, 0, fadeAmount);
            yield return new WaitForSeconds(0.03f);
            fadeAmount += 0.015f;

            if (fadeAmount >= 0.95f)
                SceneManager.LoadScene("GameOver");
        }
    }
}


public class BloodVial : MonoBehaviour
{
    private void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player"))
        {
            PlayerHealth PH = other.GetComponent();
            if (PH.Phealth != 100)
                PH.Phealth += 50;

            if (PH.Phealth > 100)
                PH.Phealth = 100;

            Destroy(this.gameObject);
        }
    }
}

Challenges & Learnings

Developing The Experiment: Nature Edition taught me how to design immersive VR mechanics while maintaining performance and user comfort. One of the biggest challenges was implementing responsive door and weapon interactions that felt natural in VR space.

I also learned how to structure enemy wave systems, trigger-based power-ups, and smooth visual transitions using Unity’s coroutine system. Balancing combat intensity with exploration made the gameplay both tense and rewarding.
