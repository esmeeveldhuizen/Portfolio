Star Delivery

A VR space delivery game made in 5 weeks with 4 developers

Project Overview

Star Delivery is a VR space delivery experience where players pilot a spaceship to deliver packages to distant planets. The game uses a racing simulator setup with a steering wheel, pedals, and gear shifter to control the ship, creating a realistic, fully immersive experience. The project was developed over five weeks by a team of four developers, while the entire art class contributed visuals in just four days. My role focused on programming the VR controls, fuel mechanics, and general game logic.

Gameplay Mechanics

In Star Delivery, the player controls the spaceship entirely through a racing simulator setup. The steering wheel turns the ship, pedals control acceleration and braking, and the gear shifter handles reverse and moving the ship up and down. The player must navigate between planets while avoiding astroids and managing fuel, collected by flying through stars scattered through space. If the ship runs out of fuel, the mission fails. This blend of realism and arcade-like challenge makes every delivery an exciting race against time.

Development Process

Our team of four developers worked collaboratively in Unity, focusing on integrating VR mechanics and realistic ship physics. I implemented movement control, fuel consumption, and collision detection, ensuring everything responded naturally to the racing rig inputs. The art team created all assets in just four days, and I was responsible for integrating them efficiently. This project strengthened my understanding of teamwork, optimization, and balancing performance with immersion in VR environments.

public class UpAndDownMovement : MonoBehaviour
{
    private LogitechGSDK.DIJOYSTATE2ENGINES rec;
    private float speed = 5; // how fast you move up and down

    void Start()
    {
        transform.position = Vector3.zero;
    }

    void Update()
    {
        rec = LogitechGSDK.LogiGetStateUnity(0);
        LogitechGSDK.LogiControllerPropertiesData actualProperties = new LogitechGSDK.LogiControllerPropertiesData();
        LogitechGSDK.LogiGetCurrentControllerProperties(0, ref actualProperties);

        GetButtons(); // Check for button input
    }

    void GetButtons()
    {
        for (byte i = 0; i < 128; i++) // go through all 128 button inputs
        {
            if (rec.rgbButtons[i] == 128) // Check if button is pressed
            {
                Gear3(i);
                Gear4(i);
            }
        }
    }

    public bool Gear3(byte button14)
    {
        if (button14 == 14)
        {
            transform.position = new Vector3(transform.position.x, (transform.position.y + (Time.deltaTime * speed)), transform.position.z);
            return true;
        }
        return false;
    }

    public bool Gear4(int button15)
    {
        if (button15 == 15)
        {
            transform.position = new Vector3(transform.position.x, (transform.position.y - (Time.deltaTime * speed)), transform.position.z);
            return true;
        }
        return false;
    }
}


public float maxAngularVelocity = 30;
public float Torque = 0.5f;

[SerializeField] private float minTurnSpeed = -2;
[SerializeField] private float maxTurnSpeed = 1;

private Rigidbody rigidbody;

[SerializeField] private const float DeadzoneMin = -1f;
[SerializeField] private const float DeadzoneMax = 1f;

[SerializeField] private GameObject wheel;
public float rotationSpeed = 100f; 
private float currentWheelRotation = 0f; 

void FixedUpdate()
{
    rigidbody.angularVelocity = Vector3.up * Mathf.Clamp(rigidbody.angularVelocity.y, minTurnSpeed, maxTurnSpeed);
}

public void OnWheelInput(float input)
{
    Rotate(input);
}
                  
private void Rotate(float NormalizedInput)
{
    if (NormalizedInput > DeadzoneMin && NormalizedInput < DeadzoneMax)
    {
        NormalizedInput = 0f;
    }

    rigidbody.AddRelativeTorque(Vector3.up * Torque * NormalizedInput, ForceMode.Force);

    currentWheelRotation += -NormalizedInput * rotationSpeed * Time.deltaTime;
    currentWheelRotation = Mathf.Clamp(currentWheelRotation, -450f, 450f);

    wheel.transform.localRotation = Quaternion.Euler(currentWheelRotation, 0, 0);
}

private void ApplyPasiveForceFeedback()
{
    LogitechGSDK.LogiPlaySpringForce(0, Offset, Saturation, Coefficient);
}


private void NoFuelLeft()
{
    if (Fuel <= 0.01)
    {
        sosCanvas.SetActive(true);
        rb.isKinematic = true;
    }
}

private void PressedX(int button)
{
    if (button == 0 && Fuel < 1)
    {
        StartCoroutine(FadeIn());
        StartCoroutine(WaitASec());
    }
}

IEnumerator FadeIn()
{
    Renderer rend = sphere.transform.GetComponent();

    for (float i = 0; i <= 1; i += Time.deltaTime)
    {
        rend.material.color = new Color(0, 0, 0, i);
        yield return null;
    }
}

IEnumerator FadeOut()
{
    Renderer rend = sphere.transform.GetComponent();

    for (float i = 1; i >= 0; i -= Time.deltaTime)
    {
        rend.material.color = new Color(0, 0, 0, i);
        yield return null;
    }
}

IEnumerator WaitASec()
{
    yield return new WaitForSeconds(1.5f);
    transform.position = bigShip.transform.position;
    StartCoroutine(FadeOut());
    Fuel = 100;
    sosCanvas.SetActive(false);
    rb.isKinematic = false;
}

Challenges & Learnings

One of the biggest challenges was fine-tuning the VR input system to synchronize perfectly with the physical racing simulator setup. Each control, from the gear shifter to the steering, required careful calibration to feel natural in VR. Balancing fuel mechanics, ship movement, and comfort was another key learning experience. This project deepened my skills in Unity physics, input systems, and hardware integration, while also teaching me how to iterate quickly with a large, interdisciplinary team.
