Tristar Triumph

A 3D platformer made entirely solo in 4 weeks, playable on PC, mobile, Steam Deck, and VR.

Project Overview

Tristar Triumph is a 3D platformer developed solo in Unity (C#) over 4 weeks. Players explore floating islands in search of 3 hidden stars. Collecting all stars unlocks a crown, and the goal is to catch the roaming chicken to win. Players have three lives and losing one occurs if they fall into water. Time taken to complete the game is tracked, adding an extra layer of challenge.

The game runs smoothly across PC, mobile, Steam Deck, and VR. All mechanics, character movement, platforming, and collectible systems were implemented from scratch, using asset packs from the Unity Asset Store for models and environment props.

Gameplay Mechanics

Players navigate a series of islands searching for three stars. Each star collected reveals a path to the next island. Once all three stars are collected, a crown appears on a chicken. Catching the crowned chicken wins the game. Players have three lives and lose one if they fall into the water. The completion time is also tracked, adding replayability and challenge.

Development Process

The game was developed entirely by me in Unity using C#. I designed all mechanics, including platform movement, player controls, star collection, crown system, and win conditions. I used an asset pack from the Unity Asset Store for models and environmental props, and ported the game to multiple platforms including PC, mobile, Steam Deck, and VR. All code, gameplay systems, and interactions were created from scratch.

public class MovingPlatform : MonoBehaviour
{
    [SerializeField] private float speed = 4f;
    [SerializeField] private int startingPoint;
    [SerializeField] private Transform[] wayPoints;
    private int i;

    void Start()
    {
        transform.position = wayPoints[startingPoint].position;
    }

    void Update()
    {
        if (Vector3.Distance(transform.position, wayPoints[i].position) < 0.02f)
        {
            i++;
            if (i == wayPoints.Length) i = 0;
        }
        transform.position = Vector3.MoveTowards(transform.position, wayPoints[i].position, speed * Time.deltaTime);
    }

    void OnCollisionStay(Collision collision)
    {
        if (collision.gameObject.CompareTag("Player"))
        {
            collision.gameObject.transform.parent = transform;
        }
    }

    void OnCollisionExit(Collision collision)
    {
        if (collision.gameObject.CompareTag("Player"))
        {
            collision.gameObject.transform.parent = null;
        }
    }
}

public class CrownPickup : Pickup
{
    [SerializeField] private GameObject winCanvas;
    [SerializeField] private Button button;                     
    [SerializeField] AudioSource winAudio;

    public override void Activate(GameObject other)
    {
        if (other.CompareTag("Player"))
        {
            CollectionManager CollectionManager = other.GetComponent();
            CollectionManager.CrownPickup.SetActive(false);
            button.Select();

            ScoreManager.Instance.TimerActive = false;
            winCanvas.SetActive(true);
            winAudio.Play();
        }
    }
}

Challenges & Learnings

Developing Tristar Triumph entirely solo taught me the full cycle of game development. The challange was to create the star collection mechanics while ensuring smooth performance across PC, mobile, Steam Deck, and VR. Another challenge was balancing player experience, tracking lives and time, and creating an engaging win condition with the crowned chicken.

This project strengthened my skills in Unity, C#, cross-platform porting, and full-game design. Creating a complete game in 4 weeks entirely on my own was a major achievement.
